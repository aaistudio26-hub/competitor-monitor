# Project Overview

## Назначение и пользователи

Competitor Monitor — локальный ИИ-ассистент для конкурентного анализа юридических услуг для бизнеса. Его фокус охватывает регистрацию и ликвидацию компаний, лицензирование и арбитраж. Пользователи — маркетологи и сотрудники юридических фирм, которые анализируют сайты, коммерческие предложения и рекламные материалы конкурентов. Аудитория самих конкурентов — предприниматели, собственники и директора.

**Ключевая ценность.** Из текста, визуального материала или сайта специалист получает структурированный разбор оффера, заметности услуг и признаков доверия. Текстовый и сайтный сценарии дополнительно оценивают CTA (призыв к действию), прозрачность цены и сроков и конкурентную угрозу. Рекомендации и оценки помогают выбрать материалы для углублённого разбора и идеи для собственного оффера.

**Гипотеза пилота.** Ассистент ускоряет первичный разбор и даёт рекомендации, которые маркетолог может использовать. Проверка гипотезы описана в [метриках](03_SUCCESS_METRICS.md).

## Функциональность и архитектура по коду

| Слой | Файлы и обязанности |
| --- | --- |
| Веб | [run.py](../../run.py) запускает Uvicorn. [backend/main.py](../../backend/main.py) обслуживает FastAPI и статический [веб-интерфейс](../../frontend/index.html). [app.js](../../frontend/app.js) вызывает HTTP API и отображает результаты. |
| Desktop | [desktop/main.py](../../desktop/main.py) — PyQt6. [desktop/api_client.py](../../desktop/api_client.py) вызывает встроенные сервисы Python напрямую. Для desktop веб-сервер не нужен. [sync_backend.py](../../desktop/sync_backend.py) копирует корневой backend в desktop. |
| Анализ | [openai_service.py](../../backend/services/openai_service.py) формирует сообщения, вызывает OpenAI Chat Completions и собирает модели из [schemas.py](../../backend/models/schemas.py). |
| Подготовка входа | [parser_service.py](../../backend/services/parser_service.py) получает данные одной страницы через Selenium/Chrome. [pdf_service.py](../../backend/services/pdf_service.py) преобразует первые пять страниц PDF в PNG. |
| Настройки и история | [config.py](../../backend/config.py) загружает локальную конфигурацию. [history_service.py](../../backend/services/history_service.py) хранит краткие записи в локальном `history.json`, по умолчанию до 10 записей. |

| Маршрут | Вход и результат |
| --- | --- |
| `POST /analyze_text` | JSON `{"text":"…"}`, минимум 10 символов. Ответ `success / analysis / error`, схема анализа `CompetitorAnalysis`. |
| `POST /analyze_image` | Multipart-поле `file` с JPEG, PNG, GIF, WebP или PDF. Ответ `success / analysis / error`, схема `ImageAnalysis`. |
| `POST /parse_demo` | JSON `{"url":"…"}`. Ответ `success / data / error`. В `data` находятся URL, title, H1, первый содержательный абзац и `CompetitorAnalysis`. |
| `GET /competitors`, `POST /collect_competitors` | Чтение настроенного списка и сбор по нему либо по переданным `urls`. `with_ai` по умолчанию `true`. В ответе по сайту есть метаописание, ссылки на услуги, контакты, найденные CTA и отдельный `error`. |
| `GET /history`, `DELETE /history` | Чтение и очистка локальной истории. |
| `GET /`, `GET /health`, `GET /docs`, `GET /redoc` | Интерфейс, ответ работающего веб-приложения и интерактивная документация API. Health не проверяет ключ, модели и Chrome. |

**Поток обработки сайта.** Selenium загружает страницу и извлекает данные. При наличии скриншота используется отдельный промпт анализа сайта с URL, title, H1 и фрагментом абзаца. При отсутствии скриншота используется текстовый промпт. При ошибке вызова Vision автоматического повтора через текст нет. В пакетном сборе проверяйте `items[].error` даже при `success:true` у ответа целиком.

## Границы применения

- Выводы относятся к переданным материалам и видимой части страницы. Парсер обрабатывает указанные URL и может найти ссылки на услуги, но не обходит их для полного аудита сайта. Сбор запускается по запросу.
- Баллы отражают суждение модели по B2B-критериям. Материалы для массовых услуг физлицам и оценка декоративного UX выходят за предмет анализа. Факты, цены и выводы перед использованием проверяет специалист.
- История содержит краткие сводки. Для сравнения версий промпта сохраняйте отчёт прогона и оценки отдельно от истории.
